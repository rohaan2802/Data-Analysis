# SSMS runbook

1. Install SQL Server (Express/Developer) + SSMS.
2. Clone this repo; note the absolute path to `Assignment #02/Assignment_2_i222327/`.
3. Open `Assignment #02_SQL.sql`.
4. Find/replace the old `BULK INSERT` machine path with your folder path.
5. Follow [`load-order.md`](load-order.md) (reorder batches or comment FKs first).
6. Execute DDL + loads in batches (`GO`).
7. Execute Task 2 analysis blocks.
8. Optional: run `NorthWind DataBase/NorthWind DataBase.sql` as a **separate** database for practice.
9. Open `docs/screenshots/` or the `*_ANALYSIS` folders to compare charts.
